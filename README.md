# PDF AI Agent

A Flask-based API server for advanced PDF manipulation and AI-powered features.

## Features

- Extract text, images, and metadata
- Summarize PDFs with GPT
- Merge, split, convert, protect, and OCR PDFs
- Generate PDF summaries from URLs
